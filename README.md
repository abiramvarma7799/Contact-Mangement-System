# Contact-Mangement-System

**Contact Management System** developed using **C++** and **Data Structures**. This project allows users to efficiently manage their contacts through a simple menu-driven interface.

## Features

* Add a new contact
* Display all contacts
* Search for a contact
* Update contact details
* Delete a contact
* Store contact name and phone number
* Simple and user-friendly menu
* Efficient data handling using data structures

## Technologies Used

* C++
* Data Structures
* Object-Oriented Programming
* File Handling

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/contact-management-system.git
```

2. Open the project folder.

3. Compile the program:

```bash
g++ main.cpp -o contact
```

4. Run the program:

```bash
./contact
```

### On Windows

```bash
contact.exe
```
